# Yuheng Demo 完整管理端集成设计

## 目标

将当前独立的 `yudao-ui-admin-vue3` 完整管理页面纳入 `yuheng-demo` 消费端，使开发运行和单 JAR 部署都能使用完整管理页面，并继续调用 `yuheng-demo` 提供的 `/admin-api`。

## 当前结构与问题

- `yuheng-demo` 是消费端 Spring Boot 工程，应用上下文根路径为 `/`，管理 API 通过 `/admin-api` 提供。
- `yuheng-demo-ui` 已通过 `yuheng-ui` 公开入口接入登录、权限、布局、system/infra 页面及消费端路由，但当前自身只包含轻量首页。
- 相邻目录 `yudao-ui-admin-vue3` 是独立 Vue 3/Vite 管理端，包含完整的 API、菜单页面和组件。此前为浏览器验证所做的 `.env.local` 和 Vite 代理更改只属于该独立仓库，不会随本次消费端迁移自动带入。
- `yuheng-demo` 工作区已有未提交的 Liquibase、后端配置和文档改动。本次实现必须保留这些工作。

## 方案

以 `yuheng-demo-ui` 作为消费端唯一正式前端工程，将完整管理端的页面、API、组件、布局、路由、静态资源和必要构建配置迁入该目录。保留 `yuheng-ui` 的平台集成边界：登录、token/租户处理、权限和平台路由继续走它的公开入口；迁入页面继续调用消费端配置的 `/admin-api`，不从相邻 `yuheng-core` 源码路径导入实现。

开发模式通过 Vite 在 `3000` 端口提供页面，并将 `/admin-api` 代理到 `48080`。生产模式由前端构建生成静态文件，再纳入 Spring Boot JAR；Spring Boot 为前端入口及客户端路由提供 `index.html` 回退，API 路由仍交由现有后端控制器处理。生产静态资源使用 Vite 哈希资源名，JAR 不含 Node 运行时。

只迁移管理端运行和构建所需内容，不把上游 Git 元数据、`node_modules`、开发者 IDE 文件、上游文档站或其他独立项目带入消费端。通过迁移清单记录来源路径，保持消费端自己的包名、锁文件和启动说明。

## 配置与启动

- 统一前端 package scripts、依赖锁文件和 CI 为消费端 `yuheng-demo-ui`。
- 本地默认服务地址使用相对路径 `/admin-api`；Vite 代理目标可由环境变量覆盖，默认值为 `http://127.0.0.1:48080`。
- 租户功能沿用当前后端租户配置；本地验证码和 API 加密开关与本地后端 profile 保持一致。
- Maven package 阶段执行锁文件安装和前端生产构建，并将 `dist` 复制到 JAR 的静态资源目录。Node/pnpm 版本在构建配置及 CI 中固定。
- README 同时说明开发启动方式和单 JAR 运行方式，后者通过后端地址访问页面及 API。

## 兼容与失败处理

- 管理端 API 地址必须始终落到 `/admin-api`，避免开发环境直连跨域或部署后引用 `localhost`。
- 未登录访问应进入平台登录页面；登录成功后读取平台权限和后端动态菜单。
- 静态资源缺失返回正常 404；只有非 API 的前端路由回退到 `index.html`，不得将 `/admin-api` 错误映射成前端页面。
- 前端构建失败时 Maven package 应失败，不应悄悄生成缺少管理页面的 JAR。
- 现有轻量业务首页由完整管理端首页替代；已有业务独立路由若确有有效消费端功能，应在迁移核查中保留并接入菜单，不默认删除未审查的业务页面。

## 验证标准

1. 消费端前端锁文件安装成功，单元测试、类型检查、平台边界检查和生产构建通过。
2. Vite 开发服务器的 `/`、`/login` 返回管理端应用，`/admin-api` 代理可访问本地后端。
3. 使用本地租户与管理员账号登录后，首页和动态权限菜单可见，刷新客户端路由仍能加载。
4. `mvn package` 生成包含 `index.html` 和静态资源的 `yuheng-demo.jar`。
5. 启动打包 JAR 后，根路径和前端客户端路由返回管理端页面，`/admin-api` 仍由后端接口响应。
6. Maven 和前端验证不覆盖或回滚本次开始前工作区已有的修改。

## 不在本次范围

- 修改 `yuheng-core` 平台功能或从上游管理端迁入业务模块之外的新后端能力。
- 将 `yudao-ui-admin-vue3` 的 Git 仓库合并或删除；它作为只读迁移来源保留。
- 设计正式生产域名、TLS、反向代理和多实例部署拓扑。
